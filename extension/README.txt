MNIT Media Grabber - personal browser tool (Chrome / Edge)

Install (one time):
1. Unzip this folder somewhere permanent (e.g. Documents\media-grabber). Do not delete it later.
2. Chrome: open chrome://extensions   |  Edge: open edge://extensions
3. Turn ON "Developer mode".
4. Click "Load unpacked" and select the media-grabber folder (the one with manifest.json).
5. Pin the icon (puzzle icon -> pin). Click it to open the side panel.

Use: open a page, play the video, press Download.
Not supported: YouTube, Netflix and other DRM-protected sites; DASH (.mpd) streams.

Full step-by-step guide: double-click guide.html (or press ? in the panel).
