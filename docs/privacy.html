Privacy Policy

MNIT Media Grabber — Chrome Extension
Last updated: October 2, 2026

Summary

MNIT Media Grabber does not collect, store, or transmit any personal data to any external server. Everything stays on your device.

What the extension does

The extension detects media URLs (video and audio) on the web pages you visit and displays them in the side panel so you can download them. It uses Chrome's built-in download API to save files directly to your computer.

Data we collect

None. Specifically:

  • No personal information is collected.
  • No browsing history is recorded or stored beyond the current browser session.
  • Detected media URLs are stored in chrome.storage.session — they are cleared automatically when the browser closes.
  • No analytics, telemetry, or crash reporting tools are used.
  • No data is sent to any server operated by the developer or any third party.

Permissions used and why

  • webRequest, webNavigation — to detect media network requests on the current tab.
  • storage — to temporarily hold detected media items during your session.
  • downloads — to save files to your computer.
  • sidePanel — to show the extension UI as a Chrome side panel.
  • scripting — to scan the page for <video> and <audio> elements.
  • declarativeNetRequestWithHostAccess — to set the Referer header required by some media servers.
  • host_permissions (<all_urls>) — required to intercept media requests on any website.

None of these permissions are used to collect data about you.

Third-party services

This extension does not use any third-party services, SDKs, or APIs.

Children's privacy

This extension is not directed at children under 13 and does not knowingly collect data from them.

Changes to this policy

If this policy is updated, the "Last updated" date above will change. The extension is a personal tool and changes are rare.
